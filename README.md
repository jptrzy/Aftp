## Directions

Write a code that will search throw a graph by using [BFS](https://en.wikipedia.org/wiki/Breadth-first_search).

Use std::queue for managing searching queue.

Program should multithread its search by using std::thread and std::ref.

In the example make it run at least 2 graphs,
so that this multithreading process is visible.
